# 苏州市公共资源交易平台 — 吴江区 API 参考

## 数据源

- **网站**: `https://ggzy.suzhou.gov.cn/wjqfzx/035006/wjCity_jyxx.html`
- **列表 API**: `GET /EpointWebBuilder/JyxxSearchAction.action?cmd=getList1`
- **详情路径 API**: `GET /EpointWebBuilder/JyxxSearchAction.action?cmd=getDetailPath`
- **详情页**: `https://ggzy.suzhou.gov.cn/jyxx/003001/003001001/{YYYYMMDD}/{infoid}.html`

## categorynum 编码规则

三类工程的 categorynum 映射：

| 大类 | 招标公告 | 招标预计划 | 详情页 URL 前缀 |
|------|---------|----------|----------------|
| 建设工程 | 003001001 | 003001024 | /jyxx/003001/ |
| 交通工程 | 003002001 | 003002007 | /jyxx/003002/ |
| 水利工程 | 003003001 | 003003015 | /jyxx/003003/ |

⚠️ 交通/水利的详情页 URL 和建设工程不同，如：
- 建设工程: `/jyxx/003001/003001001/20260716/infoid.html`
- 交通工程: `/jyxx/003002/003002001/20260714/infoid.html`
- 水利预计划: `/jyxx/003003/003003015/20260708/infoid.html`

## 详情页解析正则

⚠️ **必须先 `html.unescape()`**，因为页面含大量 `&nbsp;` 实体。

### 施工类提取（三类工程通用）

**项目业主**: 同时匹配 "项目业主" 和 "招标人"（交通/水利用不同字段名）

```python
# Pattern 1: 有"为"
m = re.search(r"(?:项目业主|招标人)\s*为\s*([^，,。；;]+)\s*[，,。；;]", text)
# Pattern 2: 无"为"
m = re.search(r"(?:项目业主|招标人)\s*([^为，,。；;]+)\s*[，,。；;]", text)
```

**合同估算价**: 建设工程用"合同估算价"，交通/水利用"项目估算金额约"

```python
# 匹配两种格式
m = re.search(r"(?:合同估算价|项目估算金额)[：:约]?\s*(\d+(?:\.\d+)?)\s*万元", text)
# 兜底
m = re.search(r"估算金额[约]?\s*(\d+(?:\.\d+)?)\s*万元", text)
```

## 设计/勘察费提取（表格型布局）

设计/勘察类的费用在详情页中是**表格型布局**，不同于施工类的 `合同估算价：XXX万元` 格式：

```
设计费指导价（万元） 工期（日历天） E3205... 项目名称 描述文本... 282 45 2.4其他
```

**提取策略**: 定位关键词 → 截取600字符segment → 子正则提取：

```python
for keyword in ["设计费指导价", "设计指导价", "勘察费指导价", "勘察指导价"]:
    idx = text.find(keyword)
    if idx >= 0:
        seg = text[idx:idx+600]
        m = re.search(r"(\d+(?:\.\d+)?)\s+(\d+)\s+2\.4", seg)  # group(1)=fee group(2)=duration
        if m: fee_wan = float(m.group(1))
        break
```

⚠️ **在全量文本上用 `.+` 正则匹配会造成灾难性回溯，进程被 SIGKILL。必须先用字符串 `.find()` 截取 segment。**

## 验证码机制

第10页 (pageIndex=9) 起需要图形验证码。使用 `starttime`/`endtime` 缩小时间窗口，确保总页数不超过9页。

## 招标预计划详情页提取（categorynum=003001024）

招标预计划页面格式与招标公告完全不同，字段名也不同：

```
招标人名称 苏州市吴江区横扇农村投资发展有限公司 投资估算 750万元（万元）
资金来源 自筹 项目概况 ... 计划招标时间 2026年08月13日
```

**提取正则**:
```python
# Owner — NOT 项目业主, use 招标人名称!
m = re.search(r"招标人名称\s*([^\s]+?)\s*(?:投资|项目)", text)

# Price — 投资估算（两种格式：带冒号和不带冒号）
m = re.search(r"投资估算[：:]?\s*(\d+(?:\.\d+)?)[\s]*[（(]万元[）)]", text)
# 示例: "投资估算 4342.05（万元）" 或 "投资估算：750万元（万元）"

# Date — 计划招标时间
m = re.search(r"计划招标时间[：:]?\s*(\d{4})年(\d{1,2})月(\d{1,2})日", text)
```

过滤: 投资估算 ≥ 20000万 (2亿) | 排除含 监理/设计/勘察/公示

### 写入流程

1. `sheet.get_cell_data` 读取现有数据做去重
2. `sheet.insert_dimension` 插入 N 行空行（index 必须 JSON number）
3. `sheet.set_range_value` 批量写入文本数据
4. `sheet.set_link` 将 col 10 URL 转为超链接（display_text="查看详情"）
5. `sheet.get_cell_data` 回读校验
